# 鱼类行为预测 · 在线分析（Behavior Predictor）

独立的上传式行为预测网站：**上传鱼类视频 / 图片，或直接输入文字描述**，即可获得
行为判定、风险评估（四级预警）与可执行的解决方案。纯静态单文件，**双击即用、
完全离线、数据不出浏览器**，也可一键部署到 GitHub Pages 在线访问。

## 使用方式

| 方式 | 操作 |
| --- | --- |
| 本地使用 | 双击 `index.html`（Chrome / Edge） |
| 在线使用 | 推送到 GitHub 仓库 → Settings → Pages → Deploy from a branch（main / root）→ 访问 `https://<用户名>.github.io/<仓库名>/` |

三种输入可任意组合（至少提供一项）：

1. **视频**（mp4/webm/mov，建议 ≤60s 含鱼群画面）：自动进行帧间差分运动分析；
2. **图片**（jpg/png）：单帧亮度与纹理粗估；
3. **文字描述**：自然语言描述现场情况（支持快捷症状标签）；
4. **水质参数**（可选滑块）：DO / 氨氮 / 水温，有实测值时评估更准。

## 输出内容

1. **行为判定**：各候选行为（浮头、狂游散乱、拒食减食、擦底蹭壁、伏底静止、
   跳塘、摄食抢食、正常巡游）的支持度排序与判定理由；
2. **风险评估**：融合风险指数 R = 0.35·溶氧 + 0.40·行为 + 0.25·氨氮（未提供
   的分量按可用分量重归一化），四级预警（安全/注意/预警/危急，阈值 0.25/0.5/0.75）；
3. **解决方案**：按知识图谱 13 类预案（预案A~H）触发，每条含触发条件、执行步骤、
   联动设备与文献依据（如应急增氧的设备组合与响应时限）；
4. **视觉分析明细**（有视频时）：运动强度时序曲线、表层运动占比、运动突变度。

## 方法论与边界（务必阅读）

- **视频/图片分析为启发式算法**（浏览器端帧间差分运动能量 + 空间分布统计 +
  突变度估计），**不是**本项目的深度检测/融合模型推理；其输出以"支持度"表述。
- **文字与水质参数路径为知识图谱规则推理**：行为本体（10 类）、阈值体系
  （GB 11607-89、Kramer 1987、UF/IFAS 等）与预案库（13 类）均来自项目知识
  图谱 v3（113 实体 / 230 关系），每条建议标注文献依据（S1~S23）。
- 本站为**决策支持参考**，不替代专业兽医诊断与现场管理判断；深度模型的
  训练与基准评测见项目主仓库说明。

## 数据安全

所有分析在浏览器本地完成（Canvas 像素级计算），**文件不会上传到任何服务器**。
